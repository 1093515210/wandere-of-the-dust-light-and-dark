# 伪装成小说的报告
伊利法乐·霍伦斯坦（Eliphalet Hornstein）为本系列最后的系统纠正<p>
欧糯拉·祖咖洛（Honora Zuccaro）为该系列旁白，在作品中为伊利法乐笔名。<p>
作者毋明释称之为观察文学<P>
讲一下为什么写这部伪装成小说的报告/伪史。理由并没有那么多。**想用文学方式记录这个烂透了的世界**，仅此而已。《红尘旅客之明暗审判》系列参考了《乱世佳人》《猎魔人》《猎人笔记》三本小说，写出来的文风不像小说像史书，计划写成自己的《约翰·克利斯朵夫》。将其称为观察文学，观察这个世界的运作方式用文学方式写出。<p>
线写得太多拉不过来，太庞大了。一人一书一世界。<p>
